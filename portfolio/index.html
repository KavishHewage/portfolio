Selected Works

Project SNL

Smart Night Lamp

Standard night lights are static and inefficient. Project SNL automates ambient lighting by using light-dependent resistors (LDRs) and motion sensors to dynamically adjust brightness based on ambient darkness and room occupancy. Programmed microcontrollers in C++ for real-time sensor processing and implemented Pulse Width Modulation (PWM) to handle smooth light fading transitions.

FloodSense

Flood Detection Node System

Early detection is critical for minimizing water damage during heavy rainfall. FloodSense utilizes a distributed network of sensor nodes that monitor rising water levels and localized environmental conditions, relaying status updates before flooding escalates. Built on C++ firmware for low-power microcontroller nodes, implementing threshold-based triggers and wireless data transmission protocols.

WaterSkimmer

Waterbody Cleaning Robot

Aquatic debris causes significant pollution while water health metrics often go unmonitored. WaterSkimmer operates along the surface layers of ponds and lakes, physically capturing floating trash in a collection bay while simultaneously recording key environmental metrics. Combines C++ for motor control and real-time sensor readout with a JavaScript web interface to visualize telemetry and control the robot remotely.
